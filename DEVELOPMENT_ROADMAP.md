# Development Roadmap

## Sprint 1 — Foundation (current)
- Architecture & data model
- Migrations
- Authentication shell
- Trip calculator service + unit tests
- Trip CRUD foundation
- Responsive design system
- Dashboard foundation
- Private attachments
- Basic audit log

## Sprint 2 — Hardening
- Dedicated authorization policies & middleware for Admin/Owner
- User management screen
- Full audit-log viewer
- Server-side currency/number normalization for Indonesian formatted inputs
- Attachment delete/replacement with audit trail
- Better validation + duplicate ticket detection
- Database indexes review

## Sprint 3 — Reporting & Export
- Excel export
- PDF report
- Daily/monthly comparison
- Price trend and quality trend
- Printable trip receipt

## Sprint 4 — Local Production
- LAN deployment guide
- Automatic database + document backup
- Restore procedure
- Health monitoring
- Error logging
- HTTPS on LAN where practical
- Production environment hardening

## Future
- Multi-estate / multi-client configuration
- Multi-tenant architecture if productized as SaaS
- Weighbridge integration
- Cloud synchronization
- Mobile PWA/offline capture
